# 演示账号

这些口令只用于演示登录，**不是**服务器数据库、MinIO 或其它基础设施密钥。请不要把服务器 `.env` 里的密码写进本文件。

统一演示口令：`CampusDemo@2026`

| 登录名 | 角色 | 姓名 | 说明 |
|---|---|---|---|
| `admin` | 管理员 | 系统管理员 | 仅管理端。可下载空模板、上传校方文档、导入【模板示例】用于演示检索、导入名单、调整审批规则、重置演示数据（重置后知识库仍为空） |
| `counselor.wang` | 辅导员 | 王敏 | 带 软工2401、软工2601，审批本班请假 |
| `teacher.li` | 任课教师 | 李老师 | 高等数学，可发布作业；考试冲突时加签 |
| `teacher.zhang` | 任课教师 | 张老师 | 大学英语 |
| `stu.chen` | 学生（新生） | 陈晓 | 2026 级软工2601，待办顶部有入学报到清单；不符合奖助 |
| `stu.lin` | 学生（高年级） | 林雨 | 2024 级软工2401，已授权成绩与困难认定，**符合**国家励志奖学金预审（不会自动提交） |
| `stu.zhao` | 学生（高年级） | 赵强 | 2024 级软工2401，GPA 未达标且未认定困难，**不够格不推**奖助提醒 |

班级：计算机学院 · 软件工程 · 软工2401（高年级）/ 软工2601（新生）。

知识库默认为空，未在管理端导入模板示例或上传校方文档前，问答只会回答「知识库中没有找到相关规定」，不会编造条款。请假结论说「按当前审批规则」，不冒充校方正文。奖助预审仍按项目字段条件匹配（林雨符合、赵强不推），引文只来自已导入文档。

建议演示顺序：管理端用 `admin` 登录 `/admin/`，在规章库下载空模板或点击「导入模板示例用于演示检索」（导入后文件名带【模板示例】）。再用 `stu.chen` 问「短假由谁审批？」查看决策过程（知识检索路径）与引用；问「明天上午去医院看病，帮我请个假」查看请假路径、为何要确认；问「新生报到当天几点前到宿舍办理入住」查看模板示例冲突裁决（【示例】20:00 优先于【示例】17:00）；问「内部掌握口径」确认无权限不漏文。用一句话发起短假并由 `counselor.wang` 审批；用 `stu.lin` 问「国家励志奖学金我能申请吗」查看奖助预审决策（须学生确认、不自动提交），用 `stu.zhao` 确认不会出现资格提醒。模糊问句如「那个事情帮我处理一下」应走不确定路径，不创建草稿。
